# Isaac “Ollie” Oloche Johnson — Artist Website

Static, dependency-free portfolio site built from the supplied artist CV, project dossier and supplied artwork/documentation images, with external project facts cross-checked against GroundWork Gallery, ArtRabbit, Goethe-Institut Nigeria, TechCabal, Art Report Africa and The Lagos Review.

## Pages
- index.html — selected works / home
- projects.html — project index
- fluid-earth.html
- dreaming-new-worlds.html — project detail
- travellers-archive.html
- exhibitions.html
- publications.html
- about.html
- contact.html

## Notes
- Unknown artwork metadata is not invented.
- Traveller’s Archive is explicitly presented as a work in progress.
- Archive imagery is labelled as development/research material and should only be publicly used once permissions/rights are confirmed.
- The site is fully local/offline once the folder is copied to a web host or opened locally.
